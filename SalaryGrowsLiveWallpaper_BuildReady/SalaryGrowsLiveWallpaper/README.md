# 월급이 자란다 LIVE

Android Studio에서 폴더를 열고 Gradle 동기화 후 **Build > Build APK(s)** 를 선택하세요.

- Android 8.0 이상, Galaxy Fold 포함 화면 크기에 맞춰 자동 배치
- 화면에 보일 때 초 단위로 Canvas를 다시 그림. 잠금/화면 꺼짐 시 그리기를 중지해 전력 절약
- 누적 금액은 현재 시스템 시각으로 매번 다시 계산하므로 화면을 다시 켜도 정확한 경과 시간 반영
- 급여일 00:00에 새 급여기간 시작, 다음 급여일 00:00까지 월급을 균등 배분
- 29~31일이 없는 달은 말일을 급여일로 간주
- 급여일을 기준으로 계산하는 추정 누적액이며 실제 근무 시간, 세금, 실수령액과는 다를 수 있음
- 삼성 One UI에서 라이브 배경화면을 잠금화면에도 적용할 수 있는지는 OS 버전과 기기 설정에 따라 다름

참고: 프로젝트는 소스 코드 제공용입니다. 이 환경에서는 Android SDK/Gradle이 없어 APK 빌드 및 실기기 테스트를 완료하지 못했습니다.
